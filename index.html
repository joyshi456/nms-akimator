Why Does This Always Work? 🤔

This is the Central Limit Theorem — one of the most magical facts in all of math:

👉 If you add up many random numbers, the result is almost always shaped like a bell.

It doesn't matter what the original numbers look like — sums of randoms turn into the bell shape.

That's why the bell curve shows up everywhere in nature!

The Galton Board 🌰

A real machine that builds a bell curve from coin flips. Drop balls and watch!

How It Works ⚙️

1. A ball drops from the top.

2. It hits a peg. Bounces left or right (50/50, like a coin flip).

3. Hits another peg. Bounces left or right again.

4. After a bunch of bounces, lands in a slot at the bottom.

5. Drop tons of balls, and the slots fill up like… a bell curve! 🔔

Hash Functions: Pretend Randomness 🔐

Plot twist: a lot of "randomness" in computers isn't actually random — it's a clever trick called a hash function.

What Is a Hash? 🤔

A hash function takes any input (a word, a number, a file) and turns it into a fixed-size scrambled output that looks totally random.

But it's not random! Same input → same output, every single time. It's a deterministic recipe.

The magic: even tiny changes to the input create wildly different outputs. This is called the avalanche effect.

Hashes Look Random 🎯

Even though hashes are deterministic, when you hash lots of different things, the outputs spread out evenly — just like real randomness!

Each bar = how many hashes started with each hex digit. They're roughly equal — the hash function spreads things out evenly across all 16 buckets.

Why Should I Care? 🌐

Hash functions power tons of stuff:

🔒
Passwords
Websites store your password's hash, not the password itself.
⛓️
Bitcoin & crypto
Every block in the chain is identified by its hash.
📁
File integrity
Two files match if and only if their hashes match.
🎮
Game maps
Minecraft generates worlds from a "seed" hashed into terrain.

Spot the Fake! 🎯

Humans are terrible at being random. Can you spot real coin flips vs sequences a person made up?

The Trick 🧠

Real random sequences have streaks — like 4 or 5 heads in a row. Humans avoid those because they "feel wrong".

So if a sequence has no long runs, it's probably faked!
