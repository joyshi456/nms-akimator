Key Words 🗝️

  • Length — how many letters in a word
  • Vowel — A, E, I, O, U (and sometimes Y!)
  • Palindrome — a word that reads the same forwards and backwards (NOON, KAYAK)
  • Anagram — same letters in a different order (LISTEN ↔ SILENT)
  • Substring — a chunk of letters inside a word (the "art" inside "smart")

Cool Properties of Words 🌟

Some words have weird, beautiful properties. Try these tools to find them!

🔍 Palindrome Checker

A palindrome reads the same forwards and backwards. Try: NOON, LEVEL, RACECAR.

🎵 Vowel / Consonant Pattern

Map each letter to V (vowel) or C (consonant). AUDIO = V-V-C-V-V. What's the pattern of yours?

📏 Alphabet Distance

Add up how far each letter jumps from the next. ZA travels 25 letters; XYZ travels just 2.

📚 Longest Alphabetic Substring

What's the longest chunk where letters go in ABC order? UNDERSTUDY contains RSTU (4 letters in order!).

🔄 Rotation Symmetry

Some letters look the same when flipped upside-down: N, O, S, X, Z, H, I, M, W (kinda). SWIMS becomes SWIMS again!

🤓 The 3Blue1Brown explanation

What's a "bit"? A bit of information is what you learn from one yes/no question. If you can split possibilities in half with one answer, you've gained 1 bit.

Why start at 8.5 bits? There are about 370 possible secret words. log₂(370) ≈ 8.5 — meaning you'd need about 8.5 perfect yes/no questions to find the answer.

What makes a great guess? A guess is good if it splits the remaining words into many small groups, so no matter the result you've narrowed it down a lot.

Each guess result is a 5-letter pattern like .YG.G — there are 3⁵ = 243 possible patterns total.

The math: For each candidate guess w, see how the remaining words split across the 243 patterns. The "best" guess is the one whose split has the highest entropy:

E(w) = − ∑ pi · log₂(pi)

(Where pi is the fraction of remaining words that produce pattern i.)

The famous result: the best opening guesses give around 5.9 bits of expected info. Top contenders include TARES, SOARE, RAISE, CRANE, SLATE.

For the second guess and beyond, the optimal word depends on what you've learned. Click 🤖 above to see the current best!
